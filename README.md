# BB Glow Books — ระบบบัญชี บีบี โกลว์ หัวหิน (เฟส 1)

เว็บแอปไฟล์ธรรมดา (HTML/CSS/JS) ไม่ต้องติดตั้งอะไร ใช้ Firebase โปรเจกต์เดียวกับ POS (`bbglowhuahin-3bb7d`) เก็บข้อมูลในคอลเลกชันที่ขึ้นต้นด้วย `acc_` แยกจากข้อมูล POS โดยสิ้นเชิง และ **ไม่แก้ไขอะไรใน POS**

## เปิดใช้งาน

| แบบ | วิธี |
|---|---|
| ทดลอง (ข้อมูลสมมติ อยู่ในเครื่อง) | เปิด `index.html?demo=1` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ |
| ใช้จริง | อัปโหลดโฟลเดอร์ `app/` ทั้งโฟลเดอร์ขึ้น GitHub repo ใหม่ (เช่น `bbglow-books`) เปิด GitHub Pages เหมือน POS แล้วเปิด `https://bbglowhuahin-cloud.github.io/bbglow-books/` |
| ทดสอบในเครื่อง | จากโฟลเดอร์ bbglow-books: `python -m http.server 8765 --directory app` แล้วเปิด http://localhost:8765 |

เปิดจากไฟล์โดยตรง (file://) ไม่ได้ เพราะใช้ JavaScript module

## ผู้ใช้ 3 ระดับ

- **เจ้าของ** ทำได้ทุกอย่าง รวมตั้งค่า ยอดยกมา ลบรายการ
- **ผู้คีย์ (เจต)** เพิ่ม/แก้รายจ่าย ผู้ติดต่อ ดึงบิล POS กระทบยอด — ลบไม่ได้ แก้ตั้งค่าไม่ได้
- **สำนักงานบัญชี** ดูและดาวน์โหลดอย่างเดียว

ตอนนี้เลือกบทบาทตอนเข้า (ตั้ง PIN ต่อบทบาทได้ในหน้าตั้งค่า) เมื่อพร้อมให้เปิด "ล็อกอินอีเมล Firebase" ในตั้งค่า โดยต้องสร้างผู้ใช้ใน Firebase Console → Authentication ก่อน แล้วใส่อีเมล=บทบาทในช่องผู้ใช้

## ลำดับการเริ่มใช้จริง (ทำครั้งเดียว)

1. ตั้งค่า → กรอกเลขผู้เสียภาษีบริษัท → **บันทึกการตั้งค่า** (ยอดยกมาธนาคารตั้งไว้แล้วตาม statement 1 ต.ค. 69)
2. ตั้งค่า → **นำเข้ารายจ่าย PEAK** (77 ใบ ต.ค.–พ.ย.) และ **นำเข้ารายการโอน** (โอนระหว่างบัญชี + เงินกรรมการ 9 รายการ)
3. หน้าหลัก → **ดึงบิลจาก POS** (ย้อนตั้งแต่ 1 ต.ค. 69 ตามที่ตั้งไว้) ใบเสร็จจะถูกสร้างและรันเลขอัตโนมัติ
4. กระทบยอด → นำเข้า statement → **โหลด statement ต.ค.–พ.ย. 69 ที่เตรียมไว้** → **จับคู่อัตโนมัติ** → ไล่รายการที่เหลือด้วยปุ่ม สร้างโอนภายใน / ลงเงินกรรมการ / สร้างรายจ่าย / เลือกคู่
5. ตั้งค่า → ใส่ยอดเงินสดนับจริง แล้วติ๊ก "ยืนยันแล้ว"

หลังจากนั้นงานประจำ: กดดึงบิล POS วันละครั้ง (หรือเมื่อจะดูตัวเลข) · เจตคีย์รายจ่ายพร้อมถ่ายรูปบิล · สิ้นเดือนนำเข้า statement กสิกรทั้ง 2 บัญชีแล้วจับคู่ · หน้ารายงานดูกำไรขาดทุน ภ.ง.ด.3/53 และส่งออก CSV ให้สำนักงานบัญชี

## นำเข้า statement กสิกร

รองรับ 2 แบบ: ไฟล์ CSV จาก K BIZ (คอลัมน์ วันที่ / ถอน / ฝาก / รายละเอียด) หรือคัดลอกข้อความจาก statement PDF มาวางทั้งหน้า ระบบอ่านบรรทัด `DD-MM-YY HH:MM ประเภท จำนวน คงเหลือ ช่องทาง รายละเอียด`

## โครงไฟล์

```
app/
  index.html  styles.css
  js/app.js        เริ่มระบบ ล็อกอิน เมนู
  js/core.js       สถานะกลาง action โมดัล
  js/store.js      Firestore / LocalStorage(demo)
  js/model.js      ช่องทางเงิน หมวดค่าใช้จ่าย การคำนวณ แปลงบิล POS
  js/util.js       รูปแบบตัวเลข วันที่ไทย CSV
  js/views/        dashboard receipts expenses contacts finance recon reports settings
  seed/            ข้อมูลจาก PEAK และ statement ต.ค.–พ.ย. 69 (สร้างด้วย tools/build_seed.py)
```
